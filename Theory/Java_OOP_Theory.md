# Java OOP – Theory Questions and Answers

**Q1. What are the four main principles of Object-Oriented Programming?**

1. Encapsulation – Wrapping data and methods into a single unit called a class.
2. Inheritance – Allowing one class to acquire the properties and methods of another class.
3. Polymorphism – Allowing one method or operation to behave in different ways.
4. Abstraction – Hiding implementation details and showing only essential features.

**Q2. What is the difference between a class and an object?**

- Class: A blueprint used to create objects.
- Object: An instance of a class containing data and methods.

**Q3. What is a constructor in Java?**

A constructor is a special method-like block used to initialize objects. It has the same name as the class and does not have a return type.

**Q4. What is inheritance?**

Inheritance allows a child class to acquire properties and methods from a parent class.

**Q5. What is method overloading?**

Method overloading means defining multiple methods with the same name but different parameter lists.

**Q6. What is encapsulation?**

Encapsulation means combining data and methods inside a class and controlling access to the data.

**Q7. What is the difference between compile-time and runtime errors?**

- Compile-time errors are detected during compilation.
- Runtime errors occur while the program is executing.

**Q8. What is the purpose of the `main()` method?**

The `main()` method is the entry point from which a Java application starts executing.
