## Project Overview

This repository contains Java programming activities based on Object-Oriented Programming concepts. It includes simple programs demonstrating classes, objects, constructors, inheritance, method overloading and basic debugging techniques.

The activities are designed to develop practical programming skills and improve understanding of Java concepts through hands-on implementation.

## Project Objectives

- To understand the fundamentals of Object-Oriented Programming.
- To learn how classes and objects work in Java.
- To implement constructors, inheritance and method overloading.
- To identify and correct errors in Java programs.
- To develop basic Java applications using practical examples.
- To understand how GitHub can be used to store and manage programming projects.
